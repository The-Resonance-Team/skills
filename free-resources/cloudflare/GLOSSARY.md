# Cloudflare Usage and Limits

This context covers Cloudflare free allocations, AI use, and low-cost upgrades.

## Language

**Add-on**:
A paid feature that extends a Cloudflare plan.
_Avoid_: Bundle, extra

**Free allocation**:
An amount of service use included at no charge.
_Avoid_: Free allowance, included use

**Hard cap**:
A usage limit that blocks additional use without a charge.
_Avoid_: Hard limit

**Neuron**:
A unit of GPU compute used by Cloudflare to measure Workers AI use.
_Avoid_: Token, credit

**Neuron rate**:
The number of Neurons charged for one unit of model use.
_Avoid_: Model rate, token price

**Workers AI**:
Cloudflare's edge AI service.

**Workers Paid**:
The $5/month Cloudflare account plan for Workers services.
_Avoid_: Workers subscription

**Zone plan**:
The plan that applies to a Cloudflare domain.
_Avoid_: Domain plan
